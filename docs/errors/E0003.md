# E0003 — 意外的符号

- 类别：解析（E0xxx）
- 严重性：error
- 相关：§5.4

## 含义

YAML 或表达式在当前位置遇到了解析器无法识别的符号。常见于：

- 单位表达式里用了不支持的写法：`W/m2`（应为 `W/m^2`）、`kg m/s^2`（缺少 `*`）；
- 表达式里用了未定义的运算符：`P = η*A*G` 中的 `=`（公式里应写 `==`）；
- YAML 缩进不一致，导致解析器把一个键当成了标量的一部分。

## 诊断示例

```json
{
  "code": "E0003",
  "severity": "error",
  "file": "module.yaml",
  "path": "auxiliaries.pv_power.eq",
  "span": { "line": 52, "col": 31, "len": 1 },
  "message": "unexpected symbol `=`",
  "expected": "an expression operator (`==` for comparison)",
  "help": "did you mean `==`?"
}
```

## 如何修复

1. 看 `span` 指向的列，确认那一个字符；
2. 单位表达式用 `*` 显式相乘，指数用 `^`（例如 `W/m^2`）；
3. 等式比较用 `==`，赋值不是表达式语法的一部分；
4. YAML 缩进统一用空格，同一层级的键必须对齐。

## 相关诊断

- E0001 缩进错误
- E0002 未闭合的字符串
- E1203 量纲不一致（单位写对了，但量纲不匹配）
