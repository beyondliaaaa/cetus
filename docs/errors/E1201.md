# E1201 — 量纲不匹配

- 类别：量纲（E1xxx）
- 严重性：error
- 相关：§5.1、P5

## 含义

一个运算的两边、一次比较、或一个声明与其表达式，量纲不同。

常见情形：

- `charge + load`：能量加功率；
- `initial: "5[m]"` 但存量声明为 `kg`；
- 观测量的 `unit` 与 `eq` 的量纲不同；
- 比较 `charge > 0[W]`。

## 诊断示例

```json
{
  "code": "E1201",
  "severity": "error",
  "file": "module.yaml",
  "path": "flows.charging.eq",
  "span": { "line": 41, "col": 18, "len": 12 },
  "message": "`+` arguments have dimensions 1 and L^2 M T^-3",
  "help": null
}
```

## 如何修复

1. 检查两边是否都用了 SI 单位下的同一物理量；
2. 需要换算时显式写单位：`1200[W]`、`2[kW*h]`；
3. 如果本意是“无量纲比例”，检查是否漏了除以基准量；
4. 只允许字面量 `0` 自动适配任意量纲；其他数字都必须带单位。

- E1208 声明的单位与表达式不符
