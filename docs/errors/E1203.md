# E1203 — 流量量纲与存量/时间不一致

- 类别：量纲（E1xxx）
- 严重性：error
- 相关：§5.3、§5.7.1

## 含义

在连续时间模型中，一条流量的量纲必须等于**目标存量单位除以时间单位**。
例如存量为 `kW*h`、时间单位为 `h`，流量必须是 `kW`（能量/时间），不是 `kW*h`。

在离散时间模型（`time.kind: discrete`）中，流量是**每步增量**，量纲等于存量
单位本身。

## 诊断示例

```json
{
  "code": "E1203",
  "severity": "error",
  "file": "module.yaml",
  "path": "flows.charging.unit",
  "message": "flow unit kW*h is L^2 M T^-2, but L^2 M T^-2 per h is L^2 M T^-3",
  "help": "a flow must be a stock unit divided by the time unit"
}
```

## 如何修复

- 把流量单位改成 `kW`（或等价的能量/时间单位）；
- 检查时间单位是否写成了 `s` 而模型按 `h` 计算；
- 若确实是转换流（S → I），确保 `from` 与 `to` 两个存量的量纲相同。
