# E1205 — 未知或不合法单位

- 类别：量纲（E1xxx）
- 严重性：error
- 相关：§5.1、ADR-0002

## 含义

单位表达式中出现了注册表不认识的符号，或语法不合法。

支持的形式：`kW*h`、`W/m^2`、`kg*m/s^2`、`1/s`、`mol/(L*s)`、`m^(1/2)`。
空格不用于表示乘法；指数用 `^`。

## 如何修复

1. 检查拼写：`Watts` → `W`，`sec` → `s`；
2. 复合单位用 `*` 和 `/`，需要分组时用括号；
3. 自定义量纲（`person`、`item`、`currency`、`bit`）必须先注册；
4. 内容仓库新增单位时，在 `content/units/dimensions.yaml` 登记后由
   `UnitRegistry::register` 注入。
