# E1211 — 参数值超出声明的范围

- 类别：量纲与取值（E1xxx）
- 严重性：error
- 相关：§5.3、E1209

## 含义

参数声明了 `range: [min, max]`，但它的 `value` 不在这个闭区间内（或不是有限数）。

`range` 是这个参数的契约：玩家用滑块或数值框调参时，内核会拒绝范围以外的值
（`Sim::set_param`）。默认值也必须遵守同一个契约，否则模型一开始就处在
「玩家无法再调回去」的状态；实验台的「恢复默认」也会把参数设回一个非法值。

## 诊断示例

```yaml
parameters:
  area: { unit: "m^2", value: 150, range: [1, 100], role: control }
```

```text
error[E1211] parameters.area.value: value of `area` (150) is outside its range [1, 100] m^2
```

`value` 和 `range` 都按参数声明的单位比较（这里是 `m^2`）。边界值本身是合法的。

## 如何修复

1. 默认值写错了：改 `value`；
2. 范围写窄了：改 `range`。如果范围来自文献或参数库，修改前先核对来源（P6），
   不确定时标为 `TODO(expert)`；
3. 不需要限制的参数，可以去掉 `range`（同时它也不会在实验台显示滑块）。

## 相关诊断

- E1209 参数范围倒置（`min > max`）。范围倒置时只报 E1209，不再报 E1211。
