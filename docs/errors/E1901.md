# E1901 — 类型已能推导，但当前范式尚未支持求值

- 类别：求值（K1 的预留分支）
- 严重性：error
- 相关：§5.2、§5.6.3、P13

## 含义

`Complex`、`Vector`、`Matrix`、`Array`、`Field`、`Table`、`Graph`、`Geometry`、
`Dataset` 这些类型在解析、名称解析和类型推导阶段都是通用的（M1 的退出标准之一），
但 M1 的求值器只支持标量、整数与布尔。

这不是模型写错了，而是引擎还没有为那个范式提供求值实现。

同一诊断码也用于**已解析、已类型检查、但当前范式尚未提供求值实现的内置函数**。
目前是 `delay1`、`delay3` 与 `smooth`：它们需要延迟状态槽，SD 子系统尚未分配。
这些函数现在在编译期被拒绝，**不会**静默求值为 0。

## 如何修复

- 如果正在写未来范式的模型：等待对应里程碑（M7 场、M9 刚体等）；
- 如果用了 `delay1`/`delay3`/`smooth`：先改用存量表达延迟，或把方程移入
  `solve:` 区块；延迟状态槽落地后才能使用它们；
- 如果只是误用了复杂类型：检查变量声明；
- 引擎开发者：实现该范式的 `Subsystem`，不要修改 `Type` 枚举（P13）。
