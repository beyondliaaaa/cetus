# E1902 — `Series` 类型只能用于查询表达式

- 类别：类型（E19xx）
- 严重性：error
- 相关：§5.2、ADR-0004（K1）、ADR-0006

## 含义

`Series` 是轨迹查询专用的值类型：它表示 `Dataset` 的一列或时间轴，用来做
`first_time` / `min` / `mean` / `max_where` / `value_at` 等聚合。模型方程、辅助变量、
流量和观测量都是**逐宏步的标量表达式**，不能出现 `Series`。

在模型文件里出现 `Series` 时，解析器和类型推导可以通过，但编译期必须报本错误，
而不是把它当成标量继续求值。

## 诊断示例

```json
{
  "code": "E1902",
  "severity": "error",
  "file": "module.yaml",
  "path": "auxiliaries.mean_power.eq",
  "message": "Series is only valid in query expressions; model equations must be scalar"
}
```

## 如何修复

1. 模型方程只写标量：把 `mean(pv_power)` 这类聚合移到课程的检查器、行为测试或
   `DatasetQuery` 里。
2. 需要按时间窗口统计时，用 `CompiledQuery::eval_in(dataset, window)`。
3. 需要把组合量暴露给课程时，在模型里声明一个标量 auxiliary/observable，而不是
   在方程里聚合整条轨迹。
