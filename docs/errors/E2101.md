# E2101 — 未定义标识符

- 类别：引用（E2xxx）
- 严重性：error
- 相关：§5.4

## 含义

表达式引用了一个不存在的参数、存量、辅助变量、观测或表名。

## 常见原因

- 参数改名后忘了同步表达式；
- 用了 `stock.charge` 这样的点号写法（当前 schema 中直接写 `charge`）；
- 大小写不一致（标识符区分大小写）；
- 在 `stocks.initial` 中引用了另一个存量（另有 E1210 专门报告）。

## 如何修复

1. 对照 `parameters` / `stocks` / `auxiliaries` 的键名；
2. 需要引用其他组件时使用 `component.var`（M4 起支持）。

## 相关诊断

- E1210 初始值依赖存量
- E2102 未知函数
