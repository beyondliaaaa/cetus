# E3101 — 辅助变量之间存在代数环

- 类别：结构（E3xxx）
- 严重性：error
- 相关：§5.4、§5.5

## 含义

辅助变量通过代数关系互相依赖，无法按拓扑序求值：

```text
a = b + 1
b = a * 2
```

## 如何修复

两种当前可用的做法（按推荐顺序）：

1. **改成存量**：把环上的一个量改为存量，用流量表达变化率；
2. **隐式求解**：把方程放进 `solve:` 区块（K5，M6 起支持）。

`delay1`/`delay3`/`smooth` 需要延迟状态槽，SD 子系统尚未实现；现在使用它们会在
编译期报 E1901，而不是静默求值为 0。等 M4 的延迟课落地后，它们才会成为打断代数环
的合法手段。

不要通过“随便改一下公式”来消除环，那通常会改变模型的物理含义。

## 相关诊断

- E1201 量纲不匹配（改写过程中常见）
