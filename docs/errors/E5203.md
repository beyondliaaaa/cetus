# E5203 — 洞或补丁的目标路径不存在

- 类别：课程（E5xxx）
- 严重性：error
- 相关：§5.4、§6.1、§8.2

## 含义

课程中的 `player_model.holes[].target`，或误解的 `patch` 键，指向了模块里不存在的字段。
V1 静态检查在把洞挖到模块上、或把误解补丁应用到模块上时解析目标路径，解析失败即报本错误。

支持的目标路径只有以下五种：

- `parameters.<name>.value`
- `stocks.<name>.initial`
- `auxiliaries.<name>.eq`
- `flows.<name>.eq`
- `observables.<name>.eq`

`<name>` 必须是课程所引用模块的真实字段名，且区分大小写。L1 的因果箭头补丁使用洞 id
作为键（例如 `{ c2: increase }`），不适用上述路径，也不能用于 `teaching[].holds`（见 E5401）。

## 诊断示例

```json
{
  "code": "E5203",
  "severity": "error",
  "file": "lesson.yaml",
  "path": "player_model.holes.h_pv.target",
  "message": "hole `h_pv` targets `auxiliaries.does_not_exist.eq`, which does not exist in the model",
  "help": "use parameters.<name>.value, stocks.<name>.initial, auxiliaries.<name>.eq, flows.<name>.eq or observables.<name>.eq, or add the field to the module"
}
```

## 如何修复

1. 对照模块的 `module.yaml`，把路径改成实际存在的字段；拼写与大小写都要一致。
2. 如果确实需要新字段，先在模块中声明并让模块通过 V0–V2，再在课程里引用。
3. 检查课程 `module` 的 id 与版本约束是否指向预期模块（例如 `energy.solar-battery@^1`）。
4. 误解补丁必须是模型补丁：键为模型路径，值为可编译的表达式或参数值。
