# E5204 — 误解来源缺失或格式无效

- 类别：课程（E5xxx）
- 严重性：error
- 相关：§6.1、§8.2、§8.7

## 含义

`misconceptions[]` 与 `layers.*.misconceptions[]` 的每个条目都必须声明 `source`：

- `source.kind` 为 `research_documented`、`exam_item`、`historical_theory` 或
  `folk_belief` 时，`source.ref` 必填；
- `source.ref` 的格式必须是 `src:<id>` 或 `mc:<id>`：`src:` 指向 `content/sources/` 的文献条目，`mc:` 指向 `content/misconceptions/` 的误解目录条目；`<id>` 不能为空，也不能包含空白。

来源库尚未实现时，V1 只校验格式，不检查 `src:<id>` / `mc:<id>` 是否真实存在（切片 1 已知限制 1）。

## 诊断示例

```json
{
  "code": "E5204",
  "severity": "error",
  "file": "lesson.yaml",
  "path": "misconceptions.m_square.source.ref",
  "message": "misconception `m_square` needs source.ref unless kind is hypothesized",
  "help": "add ref: \"src:<id>\" or \"mc:<id>\", or mark kind: hypothesized until research lands"
}
```

## 如何修复

1. 为有出处的误解补上 `source.ref: "src:<id>"` 或 `"mc:<id>"`；
2. 如果调研尚未完成，把 `source.kind` 改为 `hypothesized`、`ref` 设为 `null`，并保留
   `note` 说明待办；这会触发 W5201 警告；
3. 检查 `ref` 是否写成 `src:` 前缀，且 id 中没有空格。

## 相关诊断

- E5203 洞或补丁的目标路径不存在
- W5201 误解来源为假设性条目
- W5202 教学任务引用假设性误解
