# E5205 — 初值键不是存量

- 类别：课程（E5xxx）
- 严重性：error
- 相关：§6.1、§6.3、§6.8.2

## 含义

`tasks[].setup.initial` 或 `teaching[].setup_space.initial` 的键不是模型里的存量。
初值只能设在存量上；观测量是读取结果，不是设置结果的入口。

这条规则和 §6.3 的「任务读仪器量，不读内部存量」配套：**设置初值用存量，读取结果用仪器量**。

## 诊断示例

```json
{
  "code": "E5205",
  "severity": "error",
  "file": "lesson.yaml",
  "path": "teaching.teach-natives-1.setup_space.initial.charge_pct",
  "message": "teaching task `teach-natives-1` initial value `charge_pct` is not a stock"
}
```

## 如何修复

1. 把观测量键换成对应的存量键，例如把 `charge_pct` 改成 `charge`。
2. `setup_space.initial` 的范围可以写成引用模型参数的表达式：
   `charge: { range: ["0.2 * capacity", "capacity"] }`。
3. 读取结果（预测、拟合、判别）继续用仪器量，例如 `charge_pct`。

- E5203 洞或补丁的目标路径不存在
