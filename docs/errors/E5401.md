# E5401 — 教学任务引用的对象不可用于教学

- 类别：课程（E5xxx）
- 严重性：error
- 相关：§5.4、§6.8.2、§8.2、§12 M3

## 含义

`teaching` 区块中的任务引用了课程没有提供、或不能用于教学的对象。主要包括：

- `teaching[].holds` 引用的误解只有 L1 因果箭头补丁（例如 `{ c2: increase }`），不是可运行的模型补丁。原住民的教学任务必须持有一个能应用到真模型上的 `patch`（作用于 `parameters` / `stocks` / `auxiliaries` / `flows` / `observables`）。
- `setup_space.instruments` 中出现课程未在顶层 `instruments` 声明的仪器。
- `setup_space.controls` 中的参数不是模块中可调的参数。
- `setup_space.initial` 引用了不存在的存量或观测量。
- `setup_space` 既没有 `duration`，也没有 `inherit`。
- `variants` 引用了不存在的教学任务 id。
- `gives` 引用了课程中不存在的洞。
- `scenarios[].setup.params` 引用了模块中不存在的参数。

V1 静态检查（§8.2）在解析 `teaching` 区块时报告此错误。判别实验是否可行、差异是否足够大，
属于 V4 的 E7311；误解是否被检查器区分，属于 E7301。

## 诊断示例

```json
{
  "code": "E5401",
  "severity": "error",
  "file": "lesson.yaml",
  "path": "teaching.teach-natives-broken.holds",
  "message": "teaching task `teach-natives-broken` holds `m_load_helps`, which is not a runnable model misconception",
  "help": "give the misconception a model patch, or reference a misconception whose patch targets the module model"
}
```

## 如何修复

1. 给误解补写一个与因果箭头对应的模型补丁，再让 `holds` 引用它。
2. 在课程顶层 `instruments` 中声明 `setup_space.instruments` 用到的每个仪器，只使用已声明的仪器。
3. 只把模块中可调的参数放进 `controls`，并用 `range` 给出允许范围。
4. 为 `setup_space` 补上 `duration.max`，或者 `inherit` 一个已定义的教学任务。
5. 修正 `variants`、`gives` 与 `scenarios` 中的 id、参数名，使其能在课程与模块中解析。
