# E7201 — V2 参数扫描失败

- 类别：数值验收（E7xxx）
- 严重性：error
- 相关：§8.3、§12 M3

## 含义

V2 在参数范围内做拉丁超立方扫描（默认 64 组 × 4 个种子）时，至少一组运行失败：

- 状态出现 NaN 或 Inf；
- 不变量被违反；
- 观测量在运行结束后不是有限值；
- 仿真无法启动或推进（例如当前范式尚未实现该积分器）。

`E7201` 是模型本身在声明参数空间内不可靠的信号，不是课程设计问题。

## 诊断示例

```json
{
  "code": "E7201",
  "severity": "error",
  "file": "module.yaml",
  "path": "v2.sweep",
  "message": "numeric sweep failed: sample 7, seed 2: non-finite value in slot 0 (x)"
}
```

## 如何修复

1. 根据消息中的样本与种子复现：用 `cetus run` 设置同一组参数和种子。
2. 检查参数 `range` 是否比模型实际适用的范围更宽；必要时收窄范围。
3. 检查会导致除零、对负数取对数、无界正反馈或不变量越界的式子。
4. 给存量加合理的 `bounds`，或修正驱动它越界的流量。
5. 如果模型只在极端参数下才失败，考虑把该参数改为 `fixed`，或把课程限制在稳定区域。

## 相关诊断

- E7202 步长收敛失败
- E7203 同种子确定性失败
- W7201 存量钳制次数过多
