# E7202 — V2 步长收敛失败

- 类别：数值验收（E7xxx）
- 严重性：error
- 相关：§8.3、§5.5

## 含义

V2 用 `dt`、`dt/2`、`dt/4` 分别运行模型，要求关键观测量的差异随步长减小而单调缩小，并且
`dt` 与 `dt/4` 的 nrmse 小于 1%。以下情况会报本错误：

- 粗步长与细步长的差异没有单调缩小；
- `dt` 与 `dt/4` 的差异超过默认容差；
- 某个步长变体无法编译或运行。

常见原因是事件时间分辨率不足：零点穿越、边界钳制或 `if` 分支在宏步边界触发，步长减半时
触发时刻发生跳变。

## 诊断示例

```json
{
  "code": "E7202",
  "severity": "error",
  "file": "module.yaml",
  "path": "time.dt",
  "message": "step-size convergence failed for `charge_pct`: nrmse(dt,dt/2)=4.1e-2, nrmse(dt/2,dt/4)=4.4e-2, nrmse(dt,dt/4)=7.8e-2"
}
```

## 如何修复

1. 减小 `time.dt`，或改用更高阶的积分器（`rk4`）。
2. 把硬 `if`/阈值改成连续近似，或确认事件时间分辨率在课程可接受范围内。
3. 检查存量 `bounds` 与钳制是否在每一步都触发。
4. 如果模型本身在 `dt` 处有真实的不连续（例如离散映射），把 `time.kind` 标为 `discrete`；
   V2 会跳过连续步长收敛检查。

## 相关诊断

- E7201 V2 参数扫描失败
- W7201 存量钳制次数过多
