# E7203 — V2 同种子确定性失败

- 类别：数值验收（E7xxx）
- 严重性：error
- 相关：§5.12、§8.3、D1/D5/D7

## 含义

V2 用同一个种子把同一个模型运行两次，两次的状态哈希不同。这违反了确定性约束（P2）：
同样的输入必须得到逐位相同的结果。

常见原因：

- 遍历了 `HashMap` / `HashSet` 等无序容器；
- 使用了墙钟时间或 OS 随机数；
- 依赖了未固定版本的平台相关数学函数；
- 并行归约的求和顺序不固定。

## 诊断示例

```json
{
  "code": "E7203",
  "severity": "error",
  "file": "module.yaml",
  "path": "v2.determinism",
  "message": "same-seed native runs produced different state hashes"
}
```

## 如何修复

1. 用 `IndexMap` / `BTreeMap` 替代无序容器。
2. 所有超越函数走 `cetus-math`，不要直接调用 `f64::sin` 等。
3. 随机数只使用内核派生的具名子流，不用 `ThreadRng` / `OsRng`。
4. 不要在内核里读墙钟；时间只来自 `Sim` 的 tick。
