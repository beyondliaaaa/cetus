# W2001 — 方程引用了宏步长 `dt`

- 类别：引用警告（W2xxx）
- 严重性：warning
- 相关：§5.2、§5.7.1、P2

## 含义

`flows`、`auxiliaries` 或 `observables` 的方程里引用了内置变量 `dt`（当前宏步长）。
`dt` 是只读的内置变量，但依赖它的公式通常是建模错误：同一个物理规律在改变步长后
会得到不同的结果，也会让 V2 的步长收敛检查失败。

典型场景：用 `(capacity - charge) / dt` 之类的“每步限幅”写法。连续时间模型应该把
规律写成速率，让积分器处理步长；只有刻意按步长定义的离散规则才应该引用 `dt`。

## 诊断示例

```json
{
  "code": "W2001",
  "severity": "warning",
  "file": "module.yaml",
  "path": "flows.charging.eq",
  "message": "expression references `dt`; formulas that depend on the macro step are usually modeling errors"
}
```

## 如何修复

1. 把方程写成连续时间形式，例如把“每步最多充到容量”写成速率或 `min` 形式的流量，
   让积分器按 `dt` 积分。
2. 如果模型确实是离散规则（例如 `time.kind: discrete` 的映射），保留 `dt` 并确认
   `dt` 是规则的一部分；警告可以忽略，但要在 README 里说明。
3. 重新运行 `cetus verify --level V2`，确认步长收敛仍然通过。
