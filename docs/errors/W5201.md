# W5201 — 误解来源为假设性条目

- 类别：课程警告（W5xxx）
- 严重性：warning
- 相关：§6.1、§6.8.2、§8.7

## 含义

误解条目的 `source.kind` 为 `hypothesized`。这表示条目还没有实际读过的出处，只是
一个待调研的合理猜测。V1 仍然让课程通过，但在报告中记录 W5201，提醒作者在发布前
补齐来源。

在模块达到 `expert_reviewed` 可信等级之前，`hypothesized` 条目必须由专家在
`reviews/<module-id>.yaml` 中签字确认（§8.7）；在此之前只能用于 `draft` /
`machine_verified` 预览，不得进入主线。

## 诊断示例

```json
{
  "code": "W5201",
  "severity": "warning",
  "file": "lesson.yaml",
  "path": "misconceptions.m_square.source.kind",
  "message": "misconception `m_square` is marked hypothesized; cite a source before expert_reviewed",
  "help": "replace kind with research_documented, exam_item, historical_theory or folk_belief and add ref: \"src:<id>\" once research lands"
}
```

## 如何修复

1. 用 `skills/research-misconceptions` 找到实际读过的出处；
2. 把 `kind` 改为 `research_documented` / `exam_item` / `historical_theory` /
   `folk_belief`，并补上 `ref: "src:<id>"`；
3. 在专家签字前保持 `hypothesized` 也可以，但不要把它当作已证实条目发布。

## 相关诊断

- E5204 误解来源缺失或格式无效
- W5202 教学任务引用假设性误解
