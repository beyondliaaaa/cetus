# W5202 — 教学任务引用假设性误解

- 类别：课程警告（W5xxx）
- 严重性：warning
- 相关：§6.8.2、§8.7

## 含义

`teaching[].holds` 引用了一个 `source.kind: hypothesized` 的误解。原住民的误解应优先
使用有出处的条目（`research_documented` / `exam_item` / `historical_theory` /
`folk_belief`），这样玩家在判别实验中面对的是一种真实存在的错误理解，而不是开发者
临时编造的稻草人。

W5202 不阻止课程运行；它只记录在报告中，提醒在发布前替换为有出处的条目。

## 诊断示例

```json
{
  "code": "W5202",
  "severity": "warning",
  "file": "lesson.yaml",
  "path": "teaching.teach-natives-1.holds",
  "message": "teaching task `teach-natives-1` holds hypothesized misconception `m_constant_sun`; prefer a sourced misconception",
  "help": "replace it once research-misconceptions finds a sourced entry"
}
```

## 如何修复

1. 用 `skills/research-misconceptions` 为这个误解找到出处；
2. 更新误解的 `source`（并去掉 W5201）；
3. 如果暂时没有出处，保留 `hypothesized` 并在专家审核时说明。

## 相关诊断

- W5201 误解来源为假设性条目
- E5401 教学任务引用的对象不可用于教学
