# W7201 — 存量钳制次数过多

- 类别：数值验收警告（W7xxx）
- 严重性：warning
- 相关：§5.5、§8.3

## 含义

V2 参数扫描期间，某个存量在**单次抽样运行**中于超过 50% 的步数上被边界钳制。钳制本身是
合法的建模手段，但长期贴着边界运行通常说明模型有事件时间分辨率问题，或掩盖了流量或
参数范围的问题。

这是警告，不会单独让 V2 失败。

## 诊断示例

```json
{
  "code": "W7201",
  "severity": "warning",
  "file": "module.yaml",
  "path": "stocks.charge",
  "message": "stock `charge` clamped on up to 87.4% of steps in one sampled run (threshold 50%)"
}
```

## 如何修复

1. 检查驱动存量撞向边界的流量是否符号或量级正确。
2. 确认 `bounds` 是否是模型真实适用的边界，而不是为了掩盖发散。
3. 如果边界是设计的一部分（例如库存不能为负），在课程说明里写清楚，并保留警告作为
   模型行为的记录。
4. 必要时收窄参数 `range`，让扫描只覆盖物理上合理的区域。
