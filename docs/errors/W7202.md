# W7202 — 跨目标确定性未在本地检查

- 类别：数值验收警告（W7xxx）
- 严重性：warning
- 相关：§5.12、§8.3、ADR-0001

## 含义

`cetus verify --level V2` 在 native 下检查同种子确定性，但不会构建和运行 WASM 版本。
`native` 与 `wasm` 的状态哈希一致性由 CI 的
`scripts/check-cross-target.sh` 负责（该脚本同时对照 `crates/cetus-testkit/golden/hashes.txt`）。

因此本地 V2 通过并不代表跨目标一致；这是当前切片的已知限制。

## 诊断示例

```text
warning[W7202] v2.determinism: cross-target determinism is not run by cetus verify;
scripts/check-cross-target.sh covers it in CI
```

## 如何修复

在提交或发布前运行：

```bash
./scripts/check-cross-target.sh
```

CI 的 `Cross-target determinism (native vs wasm)` 任务已经覆盖这一步。
