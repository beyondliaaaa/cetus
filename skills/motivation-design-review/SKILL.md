# 动机设计评审（鲸鱼娘历险记 / Cetus）

> **skill 版本**：v0.1（2026-10-23）· **对应指南版本**：v0.5.2
> 指南版本高于上面的数字时，先读指南 §3.7 的最新版本；两者冲突时以指南为准，并在评审记录中指出。

## 0. 什么时候用

只要一个功能会影响玩家**为什么来、为什么留、为什么回来、为什么离开**，就要评审。包括但不限于：

- 奖励、反馈、进度显示、成就、图鉴、完成度；
- 提示、难度、卡关处理；
- 推送、通知、离线摘要、会话结束画面；
- 时间：额度、季节、活动、离线时世界是否流逝；
- 随机：天才突破、小故事、掉落、事件；
- 社交：蓝图分享、好友、排行、协作；
- 鲸鱼娘、原住民、子代理的台词与行为；
- 界面文案，尤其是按钮、确认框、倒计时、数字展示；
- 遥测、指标、A/B 测试。

拿不准时就评审。评审很便宜，事后拆掉一个已经影响玩家的机制很贵。

本 skill 只做评审，不做功能实现。

## 1. 背景（读不到指南时的最小上下文）

项目初心是**逆练应用心理学**：许多骗氪游戏把心理学用在让人花更多钱和时间上（“邪修”）；本项目用同样深的功力，服务于让人真正学会、离开游戏后生活更好（“正修”）。

**两项测试**（P15）：
1. **透明测试**：把这个机制如何作用于玩家，完整地讲给玩家听，它依然有效，玩家依然认可。
2. **生活测试**：它让玩家离开游戏后的生活更好，而不只是让玩家更难离开。

**红线**（任何理由都不实现）：
- 付费随机内容；
- 限时独占内容（永久错过）；
- 进度丢失，或以丢失进度相威胁；
- 愧疚式推送（例如“鲸鱼娘想你了”“村里的孩子在等你”）；
- 限时购买压力；
- 强制社交义务；
- 确认羞辱式界面（例如“不了，我不想变强”）；
- 以在线时长或日活为优化目标的 A/B 测试；
- 把遗忘归咎于玩家缺席的叙事；
- 有期限或拒绝有惩罚的请教；
- 用时间额度阻止学习；
- 不可累积的每日额度（等于变相签到）；
- 以“上线领取”为形式的离线收益界面；
- 带稀有度标记的故事或突破。

**奖励的形式**：奖励“理解的那一刻”，用信息性反馈（“你的模型现在能解释夜间掉电了”），避免控制性的外在奖励（“完成任务得 50 金币”）。

**指标**：只优化学习增益、回顾性认可和健康度，不以在线时长、日活为目标。

## 2. 评审步骤

### 第 1 步：说清楚这个功能

用三句话写：它是什么；玩家在什么时候遇到它；它希望玩家做出什么行为。第三句最重要：如果写不出“希望玩家做什么”，先回去问设计者。

### 第 2 步：识别它用到的心理机制

逐条对照下表，列出这个功能用到的所有机制（通常不止一个）。机制本身不分好坏，关键在于用来服务什么。

| 机制 | 邪修的典型用法 | 正修的可能用法 |
|---|---|---|
| 可变比率强化（不确定的奖励时机） | 抽卡、随机掉落 | 世界的涌现带来惊喜，但进度本身确定（例如原住民“何时突破”确定，“突破什么”随机且概率公开） |
| 损失厌恶 | 连续签到断了清零、体力溢出浪费 | 几乎没有正当用法；出现时要特别警惕 |
| 沉没成本 | “你已经投入了 100 小时” | 不用 |
| 错失恐惧（FOMO） | 限时活动、限定角色 | 不用；活动可以周期性重来 |
| 互惠与社交义务 | 公会任务、助力砍价 | 异步、无义务的互助（蓝图分享对双方都有好处） |
| 准社会关系 | “老婆”依恋、愧疚推送 | 角色关心玩家在现实中的状态，为真实的理解而高兴 |
| 蔡格尼克效应（未完成之事的惦记） | 99% 的进度条、差一点就集齐 | 收集的是理解；进度必须真实反映学习 |
| 目标梯度效应（越接近越努力） | 人为制造“差一点” | 真实的阶段目标与能力等级 |
| 稀缺与锚定 | 首充、限购、多层货币 | 将来若卖皮肤：直接标价、只卖外观、设消费上限 |
| 即时反馈与早期胜利 | 新手期高密度奖励 | **直接学习**：60 秒内第一次成功，5 分钟内第一次改变世界 |
| 好奇与信息缺口 | 标题党、悬念推送 | 小故事里指向未学知识的现象；原住民“错但不离谱”的猜想 |
| 过度理由效应 | （邪修通常不在乎） | 避免给内在动机已经足够的行为加外在奖励 |
| 自主感、胜任感、归属感 | 虚假的选择、数值膨胀 | 真实的路线选择（例如原住民路线）、有上界的改进、与原住民的羁绊 |

### 第 3 步：透明测试

**写出那段说明**。以“我们这样设计，是因为……”开头，用面向玩家的语言，把机制如何作用于玩家完整讲出来，不许含糊。然后回答两个问题：

1. 玩家知道之后，这个机制还有效吗？
2. 玩家知道之后，会认可它，还是会觉得被操纵？

判定：
- **通过**：说破之后依然有效，而且玩家会认可。例如：“新一代来请教，是复习调度为你安排的，因为讲给别人听是最好的复习。”
- **不通过**：机制依赖玩家不知情，或者说破后玩家会反感。例如：“这个进度条故意从 20% 开始，让你觉得已经走了一段。”

这段说明要原样保留在评审记录中，它也是“拆解模式”课程的素材。

### 第 4 步：生活测试

回答：这个功能练出了什么、改变了什么，是玩家离开游戏后还用得上的？

判定：
- **通过**：有具体的、可带出游戏的收益（知识、能力、习惯、健康的作息），或者至少不会让玩家更难离开。
- **不通过**：它唯一的作用是让玩家多停留、多回来，而停留和回来本身不带来学习。

辅助问题：
- 一个只想学东西、不想玩游戏的人，会觉得这个功能碍事吗？（P16）
- 一个每周只玩一次的人，和每天都玩的人相比，会因为这个功能而吃亏吗？（吃亏就是变相签到）
- 一个未成年人深夜还在玩时，这个功能会让他更想继续，还是更容易停下？

### 第 5 步：红线与常见陷阱检查

逐条对照 §1 的红线。然后检查以下陷阱：

**文案**
- [ ] 没有愧疚、焦虑、催促的措辞（“还剩 X 分钟”“再不来就……”“大家都在等你”）。
- [ ] 没有确认羞辱（拒绝选项用中性措辞，例如“今天先不了”）。
- [ ] 没有夸大损失（未处理的事件写成“在等你”而不是“正在恶化”，除非真的在恶化，且后果有上限）。
- [ ] 数字展示中性（额度显示为“这周村子还能过 3 年”，而不是一个需要补满的进度条）。

**时间**
- [ ] 没有因为玩家缺席而产生的惩罚或损失。
- [ ] 额度或冷却只限制世界的推进，不限制学习。
- [ ] 不规律的玩家不吃亏（额度可累积）。
- [ ] 有自然的停止点，没有“再来一把”式的强迫循环。

**随机**
- [ ] 随机与金钱无关。
- [ ] 概率公开。
- [ ] 进度的**时机**尽量确定，随机只出现在**内容**上。
- [ ] 没有稀有度、特效分级、“出金”式的演出。

**社交**
- [ ] 没有义务，没有“不做就拖累别人”。
- [ ] 没有按在线时长或活跃度的排名。
- [ ] 没有公开聊天（按可能有未成年人设计）。

**学习**
- [ ] 不学不能成为最优解（P11）：没有任何路径可以靠在线时长、社交、随机绕过掌握度检查而得到同等收益。
- [ ] 奖励的是理解的那一刻，反馈是信息性的。
- [ ] 想直接学某样东西的人不会被卡住（P16）。

**数据**
- [ ] 不收集评审目的以外的数据；需要同意；可导出、可删除。
- [ ] 相关 A/B 测试只以学习增益、回顾性认可、健康度为目标，并对玩家公开。

### 第 6 步：结论与修改

结论只有三种：

| 结论 | 含义 | 后续 |
|---|---|---|
| **通过** | 两项测试通过，没有触碰红线 | 记录归档，可以实现 |
| **有条件通过** | 方向可以，但有具体问题 | 列出必须修改的条目；修改后由评审者复核 |
| **不通过** | 透明测试或生活测试不通过，或触碰红线 | 给出正修替代方案（用第 2 步表格的右列）；触碰红线的功能**不得**通过 ADR 豁免 |

不通过时，**必须给出替代方案**。只说“不行”没有帮助。

## 5. 常见错误示例

| 提议 | 问题 | 正修改法 |
|---|---|---|
| 连续学习 7 天，解锁鲸鱼娘的新表情 | 连续计数 = 损失厌恶；外在奖励 | 累计理解里程碑；新表情出现在她真正为你理解了某件事而高兴的时刻 |
| 每天第一次上线送一份资源 | 上线本身被奖励，与学习无关 | 不做；回来的理由来自世界的真实需要（维护、请教） |
| 离线收益：“点击领取 3 年的村庄成长！” | 领取界面，训练“上线领奖” | 离线摘要只展示发生了什么，没有领取动作 |
| 推送：“村里的孩子们在等你回来” | 愧疚式推送 | 不推送；如果玩家开启了复习提醒，用中性措辞：“有一个复习可以做了” |
| 新部族限时出现，错过就没了 | 限时独占 | 部族一直在，或周期性出现 |
| 突破时“金色天才降临”的特效 | 稀有度演出，暗示抽卡 | 所有突破同等呈现，重点放在天才的故事和发现本身 |
| 卡关时弹出“看一段广告获得提示” | 把挫败感转化为交易 | 自动提供下一级提示，或换一个表示层 |
| 进度条故意从 20% 开始 | 透明测试不通过 | 进度条只反映真实进度 |
| 拒绝请教的按钮写“我太忙了，让他们等着吧” | 确认羞辱 | “今天先不了” |
| 好友排行榜按本周在线时长排序 | 以在线时长为目标 | 不设排行；或展示好友点亮的节点（社交照明） |
